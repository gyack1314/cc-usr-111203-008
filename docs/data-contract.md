# 潮位时间与核

hour为相对epoch的有限小时，可负；同hour完全相同(level,sigma)的行合并，内容不同拒绝，不拿行ID决胜。level的米单位与sigma相同。设计列顺序为1,t,cos(omega1*t),sin(omega1*t),...，仅后面的harmonic列受ridge惩罚。rho=0时定义同一测量对角项为s平方，任意不同记录协方差为0，避免0的0次幂约定混乱。

三个时间窗含端点且互不交叠，外期不参与beta或候选选择；窗口间没有资料无需插值。评分为给定训练beta的验证条件高斯负对数密度，包含维数乘log(2*pi)、logdet条件协方差和条件残差二次型。选后在early与validation合并的开发资料拟合，候选id仅作为同分稳定决胜。

beta协方差描述固定rho/ridge下测量噪声的抽样变化，不含候选选择误差。若要换epoch，必须一并变换截距/趋势与谐波坐标及其协方差，不能仅改数值时间却保持beta不动。现有domain只核对同刻资料和参数范围，不做拟合。
