# 调和分析方法说明

面向沿岸维护：把一次高水位中**常规潮汐**（给定频率的谐波分量加趋势）与**异常残差**分开。全部计算只在真实采样时刻上进行；缺采时段不插值、不预测，残差只表示"观测减确定性拟合"，不声明为任何气候因素的因果贡献。早期脚本把缺采线性补齐后在规则网格上拟合，会凭空造出另一种潮周期，本方法不经过任何补齐网格，从根上避免该问题。

## 设计矩阵

每行对应一次真实观测，列顺序固定：

| 列 | 含义 | 是否受ridge惩罚 |
| --- | --- | --- |
| `intercept` | 截距：epoch时刻的确定性水位 | 否 |
| `trend` | 线性趋势：每小时变化量 | 否 |
| `cos(omega=w)` / `sin(omega=w)` | 每个给定频率w（rad/小时）的余弦、正弦分量 | 是 |

`t`为相对固定epoch的小时（可负），禁止使用行序号当时间；打乱输入行顺序结果不变（有测试保证）。

## 噪声协方差与白化

`C_ij = s_i*s_j*rho^(|t_i-t_j|/time_scale)`，`0<=rho<1`；`rho=0`时同一测量对角为`s^2`、不同记录协方差为0。`s`为已知正标准差，`rho`与`time_scale`来自外给候选，**不从拟合残差回估**。同刻只允许一条测量：内容完全相同的重复行合并，内容冲突拒绝（见[资料约定](data-contract.md)）。

分解`C = L L^T`（下三角Cholesky），白化设计`Xw = L^{-1} X`。报告给出`logdet C`作为分解信息。

## 目标函数与有效秩

对每个候选`(rho, ridge)`最小化

```
||L^{-1}(y - X beta)||^2 + ridge * sum(beta_harmonic^2)
```

即`A beta = Xw^T yw`，`A = B + ridge*P`，`B = Xw^T Xw`，`P`只在谐波对角为1。截距与趋势不惩罚。

有效秩用主元Cholesky在`B`上以`rank_tolerance`（相对最大对角）判定，分三块报告：整体、未惩罚块（截距/趋势）、谐波块。识别规则：

- 未惩罚块秩亏（如所有时刻相同）：直接报错，**ridge不能顶替**；
- 谐波块秩亏且`ridge=0`：目标无唯一解，该候选判失败；
- 谐波块秩亏但`ridge>0`：可以解出，但报告仍显示秩亏、冗余列与近共线列对，**惩罚不掩盖识别问题**。

混叠（采样网格上不可分的频率）、极近频率（如`0.5`与`0.500000001`）、记录数少于列数，都会以上述秩诊断和近共线列对（|相关系数|>0.9999）显示，状态记为`deficient`。

## 候选评分与选择

只用`early`窗估计beta，对`validation`窗评**条件高斯负对数密度**：

- 条件均值 `m = C_vt C_tt^{-1} (y_t - X_t beta)`
- 条件协方差 `S = C_vv - C_vt C_tt^{-1} C_tv`
- 评分 `nll = 0.5*(k*log(2pi) + logdet S + (r_v - m)^T S^{-1} (r_v - m))`

这是代入beta的评分，不含beta估计不确定性，**验证点不用于更新beta**。选评分最小者，同分按候选id字典序取先（稳定决胜）。选后在`early+validation`合并的开发段重拟合；`external`外期不参与拟合与选择，只给冻结预测与残差。

## 系数协方差

报告`A^{-1} B A^{-1}`三明治（`B = X^T C^{-1} X`）。`ridge>0`时`A^{-1}`本身**不是**抽样协方差；`ridge=0`时退化为通常的GLS协方差`B^{-1}`。该协方差只描述固定`rho/ridge`下测量噪声的抽样变化，不含候选选择的不确定性。Monte Carlo小样本核对见`tests/test_harmonic.py`。

## 振幅与相位

每个频率`a*cos(wt) + b*sin(wt) = R*cos(wt - phi)`，`R = hypot(a,b)`，`phi = atan2(b,a)`，标准误由系数协方差delta法给出。`R <= phase_amplitude_floor`时相位不可识别，报告`phase_rad = null`并置`phase_identifiable = false`。

## 输出与跨时刻预测差

开发段每条观测给出`trend`、`tidal`、`residual`；外期只给冻结`prediction`与`residual`。同时给出观测时点的预测协方差矩阵`P = X Cov(beta) X^T`，跨时刻预测差的方差含共享系数协方差：

```
Var(p_i - p_j) = P_ii + P_jj - 2*P_ij
```

不能只取对角相加，否则忽略共享系数带来的协方差。

## 换epoch

如需平移epoch（`t_new = t_old - shift`），必须一并变换系数与协方差：截距加`trend*shift`，每个谐波的`(cos,sin)`坐标按`w*shift`旋转，协方差左乘右乘同一变换矩阵。`shift_epoch`实现该变换，并有与重新拟合对照的测试。只改数值时间而保持beta不动是错的。

## 小样本核对与演示（tests/test_harmonic.py）

- 完整`C`：逐元素对公式、Cholesky重构、logdet对3x3行列式；
- 条件核：对测试侧Gauss-Jordan求逆的显式条件公式，且`nll(联合) = nll(条件) + nll(边缘)`；
- 系数协方差：固定设计Monte Carlo（`ridge=0`与`ridge>0`），经验协方差对三明治公式，`ridge=0`时同时对`B^{-1}`与无偏性；
- 缺采：含18小时空档的资料，输出只含真实观测时刻，空档内无任何预测；
- 跨epoch：负时刻跨epoch资料可拟合，`shift_epoch`与平移后重拟合一致；
- `rho=0`：`C`退化为对角，GLS退化为加权最小二乘（对闭式解），条件评分退化为独立高斯和。
